# football_tournament

1. הוספת קבוצות והצגת הקבוצות הרשומות
2. הוספת תוצאות משחקים ועדכון נתוני הקבוצות
3. חישוב נקודות, ניצחונות, תיקו והפסדים
4. הצגת טבלת דירוג הקבוצות
5. הצגת הקבוצה המובילה
6. הצגת הקבוצה עם מספר שערי הזכות הגבוה ביותר
7. חישוב אחוזי הצלחה
8. הצגת קבוצות ללא ניצחונות
9. הצגת סיכום הטורניר
10. בדיקת פוטנציאל לזכייה באליפות


main.py - הפעלת התוכנית
menu.py - הצגת התפריט וניהול בחירות המשתמש
teams.py - הוספה והצגת קבוצות
matches.py - ניהול משחקים ועדכון נתונים
standings.py - טבלת דירוג וחישובים סטטיסטיים
validators.py - בדיקת תקינות הקלט
mock_data.py - נתוני בדיקה
